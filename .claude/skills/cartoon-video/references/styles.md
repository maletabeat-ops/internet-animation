# Стили (образцы в cartoons/)

Берёшь код из образца и копируешь хелперы. Не меняй сам образец без просьбы.

## 1. Стикмен на тетрадном листе — `stickman.html`
- Лист в клетку/линейку, красное поле, зерно бумаги. Линии «дрожат» (line boil 12 к/с): `wpath()/wline()`.
- Тело: палочки, голова-круг, простая мимика (точки-глаза, X при оглушении). Комикс-надписи «БАХ!», «БОНК!» во взрыве.
- Риг: углы конечностей от вертикали; таз ставится так, чтобы нижняя стопа касалась земли; фаза ходьбы = пройденное расстояние (без скольжения).
- Хорош для гэгов на 10–20 с, физической комедии.

## 2. Дудл-объяснялка («кругляши») — `rome.html`
- Как в роликах-объяснялках про историю: большие белые круглые головы без шеи, туники/одежда простыми фигурами,
  руки-палочки с кружками-кистями, сандалии. Плоские цвета, тонкий «дрожащий» контур, бумажная текстура (multiply, слабая).
- Фон полосами (небо/море/песок/передний план), доодл-колонна, храм, солнце.
- Эмоции: брови, рот (flat, frown, wavy, o, shout, smug, smile), большие глаза при шоке, румянец и пар при злости, знаки «!», «?!».
- Свиток с текстом, падающие монеты, крупный латинский или главный титр. Идеален для исторических и научных фактов с озвучкой.

## 3. Расписная 2D-сцена («Золотой час», Dishonored-лайт) — `city.html`
- Живописная текстура: `paint()` — заливка + боковой свет + сотни полупрозрачных мазков в клипе формы.
- Пререндер статичных слоёв (небо, дальний город, вода с отражением, набережная, пропсы) + параллакс по слоям.
- Персонаж: капсулы-конечности с градиентом (обод света с одной стороны, тень с другой), плащ и шарф с инерцией и ветром.
- Атмосфера: god rays, bloom (`screen`), пылинки, дым, сумерки (multiply + зажигание окон и фонаря), холст-оверлей, виньетка.

## 4. Карикатура «пиксар-лайк» — `paris.html`
- Фон пререндерится в 2× (камера может наезжать до ~1,9×), для крупных планов берётся размытая копия (DOF).
- Персонаж фронтально: вытянутое лицо, нос-«картошка» (переносица + круглый кончик + крылья + блик), веки (ленивый взгляд),
  густые брови, зализанные волосы с бликами, воротник и галстук. Поворот головы — сдвиг черт `fx`.
- Эмоции на словах: интерес (брови вверх), хитрость (одна бровь, веки ниже, ухмылка в угол), оскал с зубами, подмигивание.
- Монтаж планами: общий → вставка крупно (газета) → крупный план лица. Склейки по словам.
- Это максимум для рисования кодом. Объёмного 3D-света и живой мимики уровня нейросетей не будет; говори об этом честно.

## 5. Инфографика / объяснялка про технологии — `../anim.html` (ролик про интернет)
- Неоновая палитра на тёмном фоне, иконки, пакеты данных, крупные подписи. Тайминги через warp под голос.
