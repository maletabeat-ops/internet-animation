# Режиссура, камера, движение, звук

## Формат
| | Вертикаль 1080×1920 (`FMT=v`) | Горизонталь 1920×1080 (`FMT=h`) |
|---|---|---|
| Где | Shorts, Reels, TikTok | YouTube, презентации |
| Композиция | Один герой или пара по центру, глубина «вверх» (небо, башня, потолок), крупные планы лиц | Шире мизансцена: 2–4 персонажа в ряд, герой по третям, панорамы влево-вправо |
| Безопасные зоны | Верхние ~12 % и нижние ~18 % перекрывает интерфейс соцсети: там не держи лица и важный текст. Субтитры на ~86 % высоты, по центру | Субтитры на ~87 % высоты; текст держи внутри 90 % ширины |
| Камера | Наезды и проезды по вертикали, крупность чаще | Панорамы и проезды по горизонтали, больше общих планов |
| Размеры | Всё через `U = min(W,H)/1080`, а позиции через доли `W`/`H`, если сцена должна работать в обоих форматах | |

Если нужны оба формата: один файл сцены, раскладка через `FMT` (позиции персонажей, ключи `CAM`). Проверь превью обоих.

## Сюжет и раскадровка
- Хук в первые 1,5 с (вопрос, странный факт, действие), развитие, поворот, панч в конце плюс финальный читаемый кадр/титр.
- Для каждой сцены 3–5 вариантов (коротко, одной строкой), выбор с причиной. Шаблон строки плана:
  `План N (t0–t1, на словах «…»): акцент · композиция/слои · действие · текст · камера · свет/фокус · вход/выход · звук`.
- Сцены связаны причинно (одно ведёт к другому), а не просто «следующая картинка».
- Не повторяй один и тот же приём (зум-вход, вспышка) в каждом переходе.

## Камера
- Ключи `CAM = [[t, x, y, zoom, наклон], …]` с `eio`-сглаживанием; камера движется всё время, пока идёт рассказ.
- Слои по глубине: небо 0–0,2, дальний план 0,3–0,5, средний 0,6–0,8, действие 1, передний план 1,1–1,4 (быстрее камеры, можно с размытием).
- Мотивируй движение: наезд на эмоцию, отъезд на раскрытие, проезд за действием, лёгкий наклон (≤0,03 рад) на напряжении.
- Монтаж планами (общий → крупный → вставка) сильнее одного длинного зума. Склейка на слове или на ударе звука.
- DOF: на крупном плане фон размыт (пререндер `blur()`), передний план тоже можно размыть.
- Motion blur: `MB=3` в шаблоне (подкадры). Для очень быстрых объектов добавляй speed lines.

## Движение персонажей
- Замах → действие → догоняющее движение. Сжатие и растяжение у мячей и прыжков. Перед прыжком присед, после приземления просадка.
- Ходьба: фаза = расстояние / шаг, иначе ноги скользят. Таз ставь по опорной ноге.
- Вторичное движение: волосы, шарф, плащ, хвост, газета запаздывают и колышутся от ветра.
- Лицо: моргание каждые 3–4 с, взгляд туда, куда сейчас смотрит зритель, смена эмоции на ключевом слове.
- Не прячь лицо за рукой: при поднятой ближней руке в профиль она перекрывает лицо, поэтому выбирай позу заранее (см. грабли).

## Типографика
- Субтитры: Inter 900, верхний регистр, белые с чёрной обводкой, 1–3 слова, «поп» `eback` на появлении, автоуменьшение по ширине.
- Титры и вывески — часть мира: газета, свиток, вывеска кафе, надпись-взрыв. Шрифты: Inter, DejaVu Serif (курсив для «старины»).

## Звук и ритм
- Музыка под стиль, эффекты на каждое физическое действие (шаги — из фазы ходьбы автоматически).
- Важные действия и склейки совмещай со словами озвучки и с акцентами (удар, «динь», звон монет).
- Голос всегда разборчив: музыка приглушается под голосом (ducking в `sfx.py`), эффекты не громче голоса.
